# 4"平台"软件功能需求

"信息系统安全智能化测试平台"软件由测试资源部署配置、漏洞利用想定与预案、网络拓扑绘制、脆弱性扫描、漏洞攻击测试、测试评估、系统管理等组成，如图3所示。

## 4.1 测试资源部署配置功能需求

测试资源部署配置功能需求包括：

①**资产探测**：对被测目标网络进行存活主机发现与资产识别，通过ARP扫描、ICMP探测、端口探针等手段发现网络中存活的主机、开放的服务及运行的应用，为后续脆弱性扫描和攻击测试提供目标清单。平台支持IP地址、CIDR网段、域名、URL等多种目标格式的自动识别与分类。

②**HexStrike部署配置**：配置和管理HexStrike攻击框架的运行环境，包括HexStrike核心服务的启停控制、攻击模块的加载与参数配置、与平台后端的通信接口设置。HexStrike作为平台的攻击执行引擎之一，负责协调多个安全工具的联动执行。

③**虚拟环境部署配置**：管理和配置虚拟化/容器化运行环境，平台采用Podman（国产操作系统优先）或Docker作为容器引擎，自动检测并选择可用的容器运行时。所有渗透测试工具均运行在隔离容器中，按功能分为侦察（rt-recon）、漏洞扫描（rt-vuln-scan）、暴力破解（rt-brute）、漏洞利用（rt-exploit）、Web攻击（rt-web）、凭证窃取（rt-credential）、云安全（rt-cloud）、系统工具（rt-system）、网络捕获（rt-capture）等9类容器镜像，支持离线镜像文件的导入加载。

④**大语言模型LLM部署配置**：配置和管理平台所依赖的大语言模型服务，包括LLM API密钥设置、模型选择（默认DeepSeek）、API端点地址配置、超时时间与温度参数调节。平台通过OpenAI兼容接口调用LLM，支持DeepSeek、OpenAI等多种模型提供商。LLM在平台中用于智能Playbook生成、扫描结果分析、ReAct自主决策、拓扑结构化提取、报告智能生成等核心AI功能。

⑤**测试靶场部署配置**：部署和管理漏洞靶场环境，供安全测试演练使用。平台内置三类靶场的容器化部署：DVWA（Damn Vulnerable Web Application，Web应用漏洞靶场）、Juice Shop（OWASP综合Web安全靶场）、WebGoat（Web安全教学靶场）。支持靶场的一键启动/停止、运行状态监控（含容器健康检查）、以及自验证流程（启动→扫描→停止），靶场通过docker-compose管理，绑定localhost端口隔离访问。

⑥**测试工具部署配置**：管理和配置平台集成的安全测试工具库，平台集成了30余种专业渗透测试工具，涵盖网络侦察（nmap、whatweb、gobuster、ffuf、httpx、amass）、漏洞扫描（nuclei、nikto、sqlmap）、暴力破解（hydra、john、hashcat）、漏洞利用（netexec、evil-winrm、ssh-exec、rpcclient、msfvenom）、Web攻击（arjun）、凭证窃取（responder、mitm6）、云安全（cloudmapper、pacu）、网络捕获（tcpdump、tshark）等类别。工具通过容器镜像统一分发，支持容器引擎状态监控、镜像加载状态检查、以及工具与镜像的映射关系管理。

## 4.2 漏洞利用想定与预案功能需求

漏洞利用想定与预案功能需求包括：

①**漏洞利用想定**：基于脆弱性扫描结果和目标资产特征，由AI大模型自动分析攻击面并生成漏洞利用想定。想定描述对特定目标的攻击思路、攻击路径和预期效果，结合MITRE ATT&CK框架对攻击技术进行分类标注。平台通过扫描分析引擎对扫描结果进行四维结构化分析：技术栈识别、攻击面清单、风险评估（按OWASP Top 10和MITRE ATT&CK分类）、推荐攻击策略（含优先级、推荐工具和预期收益），为想定生成提供决策依据。

②**漏洞利用预案**：基于漏洞利用想定，由AI大模型自动生成可执行的漏洞利用预案（Playbook），或将扫描结果与平台预置的50余个Playbook进行智能匹配推荐。预案以JSON结构定义完整的攻击步骤序列，每个步骤包含工具标识、命令参数模板、评分权重、MITRE技术标注和教学说明。平台支持预案的编译检查（工具可用性验证、载荷解析、模板变量完整性检查）、目标适配（根据目标类型自动注入上下文变量）、以及预检门验证（目标格式、类型兼容性、工具镜像就绪等9项检查）。

③**漏洞利用战术手册**：管理和维护预置的漏洞利用战术手册库，手册按攻击类别分类，涵盖Web应用攻击、SQL注入利用、暴力破解、内网横向移动、凭证窃取与传递、Windows远程管理、Active Directory攻击、NTLM中继与欺骗、权限维持与持久化、隐蔽信道建立、拒绝服务攻击、逻辑炸弹模拟、数据外泄、云安全测试、国产操作系统攻击等场景。每个战术手册标注难度等级（入门/初级/中级/高级）、适用目标类型、MITRE ATT&CK技术映射和教学目标，支持按扫描结果自动匹配和按条件检索。

## 4.3 网络拓扑绘制功能需求

网络拓扑绘制功能需求包括：

①**网络拓扑探测**：基于脆弱性扫描结果自动提取网络拓扑结构，采用规则提取与AI增强两阶段生成策略。规则提取阶段从扫描结果中解析主机节点、开放服务端口、操作系统指纹、漏洞标注和凭证发现等信息，自动生成节点和连接关系；AI增强阶段调用大语言模型对扫描结果进行结构化拓扑分析，补充规则提取遗漏的设备类型推断、网络分段识别和连接关系推理，两阶段结果自动合并取优。

②**网络拓扑编辑**：提供交互式拓扑图编辑功能，支持节点的拖拽移动、新增主机节点和连接关系、节点属性编辑（IP地址、主机名、操作系统、设备类型、厂商、状态标注等）、服务信息编辑（端口号、协议、服务名、产品版本等）、连接属性编辑（标签、类型、备注），以及拓扑图的缩放、平移和视图重置操作。

③**网络拓扑展示**：以可视化图形方式展示网络拓扑结构，节点以状态着色的圆形图标表示（绿色=在线、黄色=告警、红色=离线、灰色=未知），显示IP地址和主机名标签，悬停展示详细服务列表；连接以类型着色的线段表示（蓝色=网关/路由、黄色=上行链路/中继、灰色=普通连接），标注连接类型。支持三栏布局：左侧扫描控制面板、中间拓扑图画布、右侧节点/连接详情面板。

④**网络拓扑信息标注**：对拓扑图中的节点和连接进行安全信息标注，包括漏洞发现标注（在节点上显示发现的漏洞名称）、凭证发现标注、服务指纹标注（从扫描输出自动识别Redis、PostgreSQL、MySQL、Grafana、Tomcat、Nginx、DVWA、MinIO等25余种服务），以及自定义备注和标签。标注信息随拓扑数据持久化存储，支持拓扑图的保存与加载。

## 4.4 脆弱性扫描功能需求

脆弱性扫描功能需求包括：

①**系统漏洞扫描**：使用Nuclei漏洞扫描引擎对目标进行系统级漏洞扫描，基于社区维护的Nuclei Templates漏洞模板库（支持自动下载更新），检测目标主机存在的已知漏洞、安全配置缺陷和合规性问题。扫描结果按模板ID、协议类型、严重等级和URL进行结构化解析，支持v2和v3两种输出格式。平台将扫描结果存入数据库，并通过WebSocket实时通知扫描进度。

②**Web漏洞扫描**：对Web应用进行多维度漏洞扫描，采用双步骤扫描策略：首先使用Nikto进行通用Web漏洞扫描（检测OSVDB漏洞、敏感路径、安全头缺失等），随后使用SQLMap进行SQL注入漏洞检测与利用验证。支持Cookie注入扫描、扫描时间限制和端口指定。扫描结果自动触发AI分析，识别技术栈、攻击面和风险等级。

③**端口扫描**：使用Nmap对目标进行端口和服务发现扫描，支持TCP/UDP端口扫描、服务版本检测（-sV）、并行度调节和端口范围指定。扫描结果解析开放端口、运行服务、产品名称和版本信息，自动推断操作系统类型（从服务指纹中识别Debian、Ubuntu、CentOS、Windows等）。端口扫描结果作为后续攻击测试的目标输入。

④**弱口令扫描**：使用Hydra暴力破解工具对目标的登录服务进行弱口令检测，支持SSH、FTP、HTTP、SMB、RDP、MySQL、PostgreSQL等多种协议的密码爆破。平台提供多种口令字典（存于data/wordlists/目录），支持自定义字典、线程数和超时时间配置。破解成功的凭证自动记录为证据，供后续横向移动和权限提升使用。

⑤**后门探测**：使用Nuclei漏洞扫描引擎结合后门检测模板，对目标进行后门和Webshell存在性探测。同时支持Active Directory域环境后门检测（通过NetExec进行AD枚举，发现异常服务账户、委派配置和Kerberos弱点）和云环境后门检测（通过CloudMapper进行云安全审计，发现过度权限和异常配置）。扫描结果按MITRE ATT&CK技术进行标注。

## 4.5 漏洞攻击测试功能需求

漏洞攻击测试功能需求包括：

①**数据抵近窃取攻击测试**：模拟攻击者通过漏洞利用接近目标数据并实施窃取的攻击链，包括SQL注入获取数据库内容、文件包含读取敏感文件、Webshell上传实现远程代码执行、HTTP隧道建立数据外泄通道等攻击技术。平台通过战役引擎按阶段编排攻击步骤，阶段间通过artifact传递攻击成果（如获取的凭证、数据库内容、文件哈希），实现从初始访问到数据窃取的完整攻击链自动化执行。

②**信息篡改欺骗攻击测试**：模拟攻击者对目标信息进行篡改或实施中间人欺骗攻击，包括DVWA文件篡改攻击、NTLM中继攻击（Responder+Mitm6欺骗域认证）、ICMP隐蔽信道建立、HTTP响应注入等攻击技术。平台支持蓝队对抗干预机制，可在攻击执行前设置主机隔离、端口封锁和路径封锁等防御措施，验证攻击在对抗条件下的有效性。

③**关键设备夺控攻击测试**：模拟攻击者对关键设备实施远程控制和权限夺取，包括WinRM远程Shell获取（Evil-WinRM）、SSH远程命令执行、SMB哈希传递攻击（Pass-the-Hash）、Active Directory域控攻击（AS-REP Roasting、密码喷洒、Kerberoasting）、Windows持久化后门植入等攻击技术。平台通过ReAct自主决策引擎，根据每步执行证据动态调整攻击策略，发现新攻击面时自动插入攻击步骤。

④**跨网致瘫攻击测试**：模拟攻击者对目标网络或服务实施拒绝服务攻击，包括HTTP洪水攻击（模拟大规模HTTP请求耗尽服务资源）、ICMP洪水攻击、TCP SYN洪水等攻击技术。平台对DoS类攻击实施严格的安全控制，包括攻击强度限制、持续时间控制、目标范围约束，以及预检门对攻击目标的合法性验证，确保攻击测试在可控范围内进行。

⑤**无线攻击测试**：模拟无线网络环境下的攻击行为，包括无线接入点伪装（Evil Twin）、无线凭证窃取、蓝牙设备探测等攻击技术。平台通过容器化工具链支持无线攻击工具的隔离执行，攻击结果按MITRE ATT&CK无线攻击技术（Tactic: TA0062）进行标注和评估。

## 4.6 测试评估功能需求

测试评估功能需求包括：

①**网络数据捕获**：在攻击测试执行过程中对目标网络流量进行实时捕获，使用tcpdump/tshark在容器中执行网络抓包，支持按协议、端口、主机等条件过滤捕获，支持定时捕获和手动触发捕获两种模式。捕获的PCAP文件存储至本地目录，供后续分析使用。捕获任务通过WebSocket实时通知状态变更。

②**网络数据分析**：对攻击测试产生的网络流量和执行证据进行结构化分析，平台内置规则引擎（24条规则覆盖nmap端口发现、Nuclei漏洞、SQLMap注入、Hydra破解、Gobuster目录枚举等），对每步工具输出进行模式匹配，自动标注MITRE ATT&CK技术ID和推荐后续攻击工具。同时通过评分引擎对攻击测试进行量化评分，评分维度包括步骤执行得分（按Playbook预设分值）和MITRE技术覆盖加分（覆盖技术数/114×20分），最终输出百分制评分和字母等级（A/B/C/D/F）。

③**安全态势感知**：综合多次攻击测试的执行结果和证据记录，对被测系统的整体安全态势进行感知和呈现。通过攻击面的覆盖程度、漏洞利用成功率、凭证窃取情况、横向移动路径等维度，构建被测系统的安全态势画像，以可视化方式展示各维度的安全状态。

④**安全态势分析**：基于安全态势感知数据，对被测系统的安全薄弱环节进行深度分析，识别最易被突破的攻击路径、最严重的漏洞组合、最薄弱的防御环节。分析结果结合MITRE ATT&CK框架，标注被测系统在攻击技术矩阵中的覆盖情况和防御差距，为安全加固提供优先级建议。

⑤**安全态势展示**：以可视化方式综合展示被测系统的安全态势评估结果，包括攻击测试评分、MITRE ATT&CK技术覆盖热力图、攻击路径拓扑图、漏洞严重程度分布、证据时间线等。支持测试报告的自动生成与导出，报告格式支持DOCX、PDF、HTML三种，报告内容包含执行概要、评分详情、逐步骤执行结果、证据记录和加固建议，报告状态支持draft→reviewed→published的流转管理。

## 4.7 系统管理功能需求

系统管理功能需求包括：

①**任务管理**：管理和监控平台中所有攻击测试任务的执行状态，包括扫描任务、执行运行、流水线任务和战役任务的创建/查询/取消/删除。任务状态通过WebSocket实时推送，支持按状态、目标、类型等条件过滤查询。任务执行记录完整保留，包含每步工具调用、执行结果、证据记录和时间戳，支持任务的历史回溯和审计追踪。

②**用户管理**：管理平台用户账户的创建、查询、更新和删除，支持用户登录认证（JWT双Token机制：access_token 2小时有效期 + refresh_token 7天有效期，支持Token轮换）、密码管理（bcrypt哈希存储，支持明文密码首次登录自动升级）。用户信息包括用户名、密码哈希、角色、显示名称等，管理员可对用户进行全生命周期管理。

③**权限管理**：基于角色的访问控制（RBAC）系统，定义5种角色：管理员（admin，测试控制端，全部7模块读写权限）、教师（teacher，测试控制端，全部7模块教学子集权限）、操作员（operator，攻击测试端，拓扑+扫描+攻击模块权限）、学习者（student，受限访问，可执行扫描和攻击但不可修改配置）、观察者（viewer，只读权限）。权限覆盖16个功能域，运行时支持RBAC规则的热修改（存入数据库立即生效）。

④**加密锁校验**：通过硬件加密狗（USB Key）对平台软件的合法使用进行校验，防止未授权复制和使用。平台启动和运行时定期验证加密锁的存在性和合法性，加密锁校验失败时限制平台功能的使用。

⑤**测试报告自动智能生成**：基于攻击测试的执行结果和评分数据，自动生成结构化测试报告。报告内容包括执行概要、Playbook信息、目标信息、评分详情（百分制+字母等级+MITRE覆盖）、逐步骤执行结果（工具、参数、成功状态、输出预览）、攻击证据汇总和加固建议。支持AI辅助生成报告摘要和加固建议，报告状态支持draft→reviewed→published的流转管理。

⑥**测试报告管理**：对生成的测试报告进行全生命周期管理，支持报告的查询、编辑、状态流转和多种格式导出。导出格式支持DOCX（基于模板的Word文档）、PDF和HTML三种，支持自定义报告模板（模板存放于data/report-templates/目录）。提供一键生成并导出功能，简化报告交付流程。
