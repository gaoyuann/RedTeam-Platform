# 扫描页布局与进度

扫描页沿用 Qt Widgets 和现有扫描接口。进度区参考本机 `/home/zxf/code/pentagi-v3/src/ui/pages/scan/VulnerabilityScanPage.cpp` 中的 `buildVulnerabilityListUi` 和 `updateVulnerabilityProgress`，参考仓库仅作只读检查。

## 图形进度

- 使用 12 像素高、6 像素圆角的进度条，与视图选择、百分比 / 计数、状态点及扫描操作共用一行工具栏，不再单独占用标题栏或进度卡片。
- 具备真实结束计数时，以当前已创建的扫描项计算进度，例如 `50% · 1 / 2`；百分比不代表覆盖完整或验证成功，结束数量包含失败、取消和部分完成。
- 扫描内部进度无法量化、报告仍在处理，或工具结束状态未确认时，使用流动动画和 `--%`，不生成推测百分比。
- 状态点和进度条区分蓝色进行中、绿色已结束、橙色待核对 / 待确认以及红色失败。工具停止未确认时继续轮询。
- 当前检查、轮次、等待原因和异常说明移至悬停提示及“查看检查详情”；“过程日志”按需展开。只用最新一条调度动作描述进展，历史运行记录不会覆盖后来的完成状态。

## 布局和刷新

- 网络扫描视图默认收起左侧扫描任务栏，独立扫描和没有记录的情况也不展示空侧栏。点击“扫描任务”可展开，切换子功能保留用户的展开选择；源码扩展隐藏网络任务栏。独立视图工具栏保留“新建扫描”，打开当前类型的原有表单；任务范围内沿用测试任务入口。
- 双层页签改为一处“漏洞列表 / 推荐与生成方案 / 源码扫描”视图选择，保留原有工作区及程序跳转，选择状态双向同步。源码视图收起网络扫描进度及操作。
- 列表标题、全选、选择计数、载荷、验证、分类及批量打开合并为一行；缩短按钮文字，完整操作说明保留在悬停提示。缩小扫描页内部间距，隐藏表单不再撑大当前视图。
- 相同筛选的请求合并。响应相同不重建结果行；变化时保留发现编号对应的当前项、勾选、分组展开状态和滚动位置。后台刷新不改变日志展开状态。
- 多页结果通过既有分页接口读取相同范围，使用首批返回的 `through` 固定分页边界，全部成功后替换。中途失败保留原结果。
- 整体刷新失败时保留可读结果、停止动画并禁用依赖当前结果的操作；加载更多失败只影响新增页。成功恢复后恢复操作。
- 切换任务、筛选或记录时，继续校验请求版本和任务范围，旧响应不能覆盖新视图。缺少 `scan_sources` 的旧响应允许当前范围的子任务列表回填。

## 验证

使用隔离接口样例，不创建真实扫描或调用模型。回归覆盖真实百分比、未知进度动画、紧凑布局、悬停信息、状态转换、请求合并、235 条记录的分页保留、失败恢复、工具停止未确认，以及三档缩放下的小窗口布局。

```sh
cmake --build build --target RedTeam-Platform RedTeam-Platform-Batch16Checks -j 4
ctest --test-dir build -R '^ui-context-' --output-on-failure -j 3
```

`REDTEAM_SCAN_PRESENTATION_ONLY=1` 可单独运行扫描页专项检查；`REDTEAM_SCAN_SCREENSHOT_DIR` 可保存实际 Qt 控件的进度条和整页截图，截图不提交到仓库。

此前回归发现的加载更多失败误禁用原页、旧接口子任务列表回填、关闭漏洞窗口后丢失后续分页等兼容问题均已修复；事件刷新用例等待初始读取结束后，仍严格核对 WebSocket 事件实际触发请求。

本次验证结果：应用与 UI 回归目标编译通过；带截图的扫描页专项检查 27 项通过。`REDTEAM_SCAN_PRESENTATION_ONLY=1 ctest --test-dir build -R '^ui-context-' --output-on-failure -j 3` 三档缩放全部通过。

完整命令 `ctest --test-dir build -R '^ui-context-' --output-on-failure -j 3` 本次三档均在资源配置页的 `runtime configuration fits the small application workspace with only the image table scrolling` 断言处失败，尚未执行到扫描页检查。失败时资源配置内容高 862 像素、镜像表高 665 像素，工作区高 480 像素，存在外层纵向溢出；该配置页布局问题未在本次扫描页任务中修改。扫描专项通过不能替代完整 UI 回归通过。

紧凑布局验证：应用及回归目标编译通过，完整 `ui-context-1`、`ui-context-1.25`、`ui-context-1.5` 均通过。专项新增完整应用窗口的空列表、新建扫描表单、来源选择、长中文名称和小窗口检查；在展开全局功能区的 1366×850、1024×720 窗口中，漏洞表占扫描工作区至少 60% 高度和工作区视口至少 90% 宽度，整张表位于视口内，不依赖外层滚动。1024×600 的扫描区要求结果表高至少 360 像素，表头距页面顶不超过 150 像素。此前记录的资源页完整回归失败不再出现在本次完整回归中。
