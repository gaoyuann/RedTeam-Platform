# 后端不可用时进入界面

2026-11-02 恢复已有修复：`7e18715` 曾增加免密码访客按钮，`f2e3ee5` 已删除该按钮；本次发现当前 `main` 仅包含 #114，而 #115 合入了功能分支，导致登录页仍显示旧入口。现同步已有的按钮删除、提示文案和小屏滚动修复，账号缓存校验及原来的登录流程保持。应用、Batch16Checks 和 LoginChecks 构建通过；`ctest --test-dir build -R '^(ui-login|ui-task-dialog-)' --output-on-failure -j 2` 为 4/4 通过，真实桌面 2 倍缩放下的深／浅登录布局检查通过，已查看登录页截图。没有修改本机登录配置或关闭业务窗口。

登录继续使用服务器上的原账号，无需创建另一套本地账号。成功在线登录后，客户端按服务器地址、用户名保存带随机盐的 PBKDF2-SHA256 校验值及该次角色，不保存额外的明文密码。

后续登录遇到连接拒绝、主机不可达、超时等传输错误，或服务器返回 HTTP 5xx 时，客户端使用缓存校验输入的密码；匹配即可进入主界面。后端明确返回 HTTP 401／403 时不会离线放行，并删除该账号在当前服务器下的缓存。服务器恢复后，再次在线登录会更新缓存。

登录页仅保留用户名、密码、记住密码及“退出／登录”操作。“离线打开界面”访客按钮已删除；无缓存、账号不匹配或密码错误时，须连接后端并通过账号验证后进入。

主界面状态栏标明“离线”。离线登录不生成或沿用 JWT，扫描、在线任务、报告数据和用户管理仍需要服务器提供服务并验证身份。后端恢复后，退出登录再用原账号登录；“检测连接”只检查可达性，不会自动恢复认证。

缓存位于 Qt 的 `RedTeam/RedTeam-Platform` 用户配置中，使用 `offlineLogin/` 键。原“记住密码”设置保持原行为；离线缓存独立于该选项，不读取后端数据库，也不会同步到其他终端。此前版本登录过的终端，需要在更新后成功在线登录一次才会建立缓存。

验证：`cmake --build build --target RedTeam-Platform RedTeam-LoginChecks -j 4`；`ctest --test-dir build -R '^ui-login$' --output-on-failure`。测试使用临时用户配置和回环模拟服务器，不修改真实账号、配置或数据库。
