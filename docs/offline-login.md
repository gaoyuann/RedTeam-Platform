# 后端不可用时的本机密码校验

2026-11-02 恢复已有修复：`7e18715` 曾增加免密码访客按钮，`f2e3ee5` 已删除该按钮；排查时 `main` 仅包含 #114，而 #115 合入了功能分支，导致登录页仍显示旧入口。现同步已有的按钮删除、提示文案和小屏滚动修复，账号缓存校验及原来的登录流程保持。应用、Batch16Checks 和 LoginChecks 构建通过；`ctest --test-dir build -R '^(ui-login|ui-task-dialog-)' --output-on-failure -j 2` 为 4/4 通过，真实桌面 2 倍缩放下的深／浅登录布局检查通过，已查看登录页截图。没有修改本机登录配置或关闭业务窗口。

登录界面保持用户名、密码、记住密码及“退出／登录”操作。输入原账号密码，点击“登录”；后端正常时由服务器验证。后端连接拒绝、主机不可达、超时或返回 HTTP 5xx 时，客户端自动用本机缓存校验输入的账号密码，通过后进入主界面。没有免密码访客入口。

成功在线登录后，客户端按服务器地址、用户名保存带随机盐的 PBKDF2-SHA256 校验值及该次角色，不保存额外的明文密码。本机密码校验独立于“记住密码”选项，原选项保持原行为。首次使用或旧版本尚未建立缓存的终端，需先成功在线登录一次；无缓存、账号不匹配或密码错误均不能进入。后端明确返回 HTTP 401／403 时不会使用缓存放行，并删除该账号在当前服务器下的缓存。再次在线登录成功后会更新缓存。

主界面状态栏标明“离线”。本机校验通过后不生成或沿用 JWT，扫描、在线任务、报告数据和用户管理仍需要服务器提供服务并验证身份。后端恢复后，退出登录再用原账号登录；“检测连接”只检查可达性，不会自动恢复认证。

缓存位于 Qt 的 `RedTeam/RedTeam-Platform` 用户配置中，使用 `offlineLogin/` 键，不读取后端数据库，也不会同步到其他终端。

显示缩放保留 WSLg 缺失 DPI 的进程内补偿，显式 Qt 缩放设置优先；原生 Linux 继续跟随 Qt／桌面缩放。登录窗口保留原来的居中卡片、配色和控件尺寸；小屏幕下内容可纵向滚动，保证登录操作可达。

验证：`cmake --build build --target RedTeam-Platform RedTeam-LoginChecks RedTeam-Platform-Batch16Checks -j 4`；`ctest --test-dir build -R '^ui-login$' --output-on-failure`。登录专项使用临时用户配置和回环模拟服务器，不修改真实账号、配置或数据库。

本轮构建通过；登录专项 13 项通过，覆盖在线成功后断网、本机错误密码、无缓存、服务器 401／403 拒绝、503 故障及待响应时关闭窗口。深浅主题在本机桌面及显式 1.25／1.5／2 倍缩放下通过布局检查，2 倍缩放的完整登录专项也通过；紧凑工作区专项 32 项通过。首轮 2 倍布局检查发现 Qt 对输入框的 `ensureWidgetVisible` 只保证光标区域可见，已改为实际滚动视口并保留完整控件边界断言，重跑通过。已核对真实 Qt 截图；本轮未部署服务器或云笔电。
