```bash

docker start dvwa

./build/frontend/RedTeam-Platform
```

   ```
   [OK] 端口扫描      [██████████] 已完成
   ```

## 备用

### 推荐的稳定 Playbook（按优先级）

| 优先级 | Playbook | 步骤数 | 工具 | 说明 |
|--------|----------|--------|------|------|
| ⭐⭐⭐ | `web_recon_basic` | 3 | nmap, nmap, gobuster | **最推荐**：3步全成功，有证据，简单易懂 |
| ⭐⭐ | `recon_nmap_basic` | 3 | nmap×3 | 纯nmap侦察，最稳定 |
| ⭐⭐ | `web_server_scan_nikto` | 2 | nikto×2 | Web漏洞扫描 |
| ⭐ | `dir_enum_ffuf` | 2 | ffuf×2 | 目录模糊测试 |
| ⭐ | `demo_web_full_killchain` | 5 | nmap→whatweb→gobuster→nuclei→hydra | 完整杀伤链，whatweb可能失败 |

### 如果杀伤链执行失败

1. 切换回 **「漏洞利用想定与预案」**
2. 选择 **「Web Recon Basic」**（web_recon_basic）
3. 目标输入 `172.17.0.2`，点击 **「执行此 Playbook」**
4. 10-15秒后完成，3步全 ✅
5. 口述："这是更简洁的3步侦察链，同样展示自动化流程"

### 如果一键测试中途失败

- 若某阶段失败，点击 **「重试当前阶段」** 按钮（黄色），从失败阶段重新开始
- 若「生成攻击方案」阶段失败（LLM 不可用），系统会自动回退到匹配已有 Playbook，无需手动干预
- 若回退匹配也无可用 Playbook，才会进入 Failed 状态，此时可点击「重试当前阶段」
