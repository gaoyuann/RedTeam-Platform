# 顶端全局搜索

在顶端输入关键词并按回车打开搜索窗口；`Ctrl+K` 可聚焦顶端输入框。窗口内输入后等待 300 毫秒自动搜索，也可按回车立即搜索。选中结果按回车或双击打开，Esc 关闭窗口。

当前搜索范围：

- 模块名称：直接进入对应页面；普通用户不显示系统管理入口。
- 当前账号可见任务：匹配任务名称、任务编号、目标或创建者，打开任务概况。
- 当前账号可见报告：匹配标题、报告编号、任务编号或目标；任务追溯报告打开对应任务报告，历史报告进入结果与报告列表。

空关键词只显示模块入口，不请求业务数据。关键词最多 120 个字符；任务和报告分别每批读取 50 条，点击“加载更多 / 重试失败项”继续读取。接口失败时保留成功来源的结果，明确提示结果不完整，并允许重试。清空、修改关键词或关闭窗口后，旧请求不会再更新结果。翻页结果按编号去重；翻页期间记录删除导致的空页视为已读完。索引使用偏移分页，数据持续变化时可能遗漏移动到已读页的记录，重新搜索可刷新结果。

搜索复用 `/api/pipelines/analysis-index` 和 `/api/reports/index` 的鉴权及只读接口，不执行扫描、分析、报告生成或导出。加密锁锁屏时搜索窗口关闭且入口禁用。

当前不检索资产明细、预案正文、知识库正文、日志或附件内容；这些模块可以通过模块名称找到入口。历史报告没有可靠的任务归属，因此不推断任务关联。

开发验证：

```sh
cmake --build build -j 4
ctest --test-dir build --output-on-failure -R 'ui-global-search|ui-context|ui-dashboard'
```

`ui-global-search` 使用本地模拟 HTTP 接口验证特殊字符、分页、空结果、失败重试、越权响应拒绝、分页期间记录减少及重复、报告类型与归属校验、部分接口失败、旧响应隔离、键盘打开及请求期间销毁窗口。无需启动后端或访问运行数据库。

`ui-context-1`、`ui-context-1.25`、`ui-context-1.5` 还通过主窗口和模拟接口验证：顶端回车打开搜索、任务结果进入对应概况、报告结果定位到指定任务报告、锁屏关闭搜索并禁用入口、解锁恢复，以及请求未完成时按 Esc 关闭窗口。测试显式控制锁屏状态，不访问加密锁硬件；同时检查导航只发送 GET 请求。
