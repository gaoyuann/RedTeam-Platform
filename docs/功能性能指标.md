# 信息系统渗透智能化测试平台 — 功能性能指标

## 一、功能指标

| 序号 | 功能项 | 指标描述 |
|------|--------|----------|
| 1 | **渗透测试模块数** | 7个一级模块、28个二级子功能 |
| 2 | **资源部署配置** | 支持平台健康检测、LLM接口配置、沙箱引擎切换（Podman/Docker）、容器镜像管理、工具注册管理、系统参数配置，共6项配置能力 |
| 3 | **漏洞利用预案** | 支持Playbook创建/编辑/删除/查询，按攻击基线分组筛选，支持AI自动生成Playbook，步骤级编排与执行 |
| 4 | **网络拓扑探测** | 支持基于扫描结果AI生成网络拓扑图，交互式节点拖拽/缩放/平移，节点属性编辑（IP/主机名/OS/服务等），拓扑图保存 |
| 5 | **脆弱性扫描** | 支持4种扫描类型（端口扫描/漏洞扫描/Web扫描/暴力破解），扫描自动执行，3秒轮询状态，结果结构化存储，基于知识图谱智能推荐Playbook |
| 6 | **漏洞攻击测试** | 支持Playbook按步骤执行，3种攻击类别（数据窃取/信息篡改/设备控制），目标历史补全，执行证据记录 |
| 7 | **测试评估** | 支持步骤级评分+MITRE ATT&CK覆盖率加分（覆盖114项技术），自动生成测试报告，攻击证据查看 |
| 8 | **系统管理** | 5角色用户管理（admin/teacher/student/operator/viewer），班级管理，课程作业与提交管理，知识图谱可视化与检索 |
| 9 | **知识图谱** | 3,190个节点（13种类型）、5,681条关系边（10种类型），含MITRE ATT&CK全量战术/技术/缓解措施数据 |
| 10 | **安全工具集** | 内置28+安全工具，涵盖侦察（nmap/httpx）、漏洞扫描（nikto/nuclei/sqlmap）、暴力破解（hydra/john/hashcat）、漏洞利用（evil-winrm/netexec）、Web测试（arjun）、凭证窃取（responder/mitm6）、云安全（cloudmapper/pacu） |
| 11 | **容器化执行** | 9类容器镜像（Alpine基础），Podman/Docker/本地三级回退执行引擎，工具输出上限2MB/次 |
| 12 | **审计日志** | 全操作审计追踪，支持按类型/工具/执行/时间范围查询与统计 |
| 13 | **国产化适配** | 前端基于Qt5/C++，兼容银河麒麟/统信UOS；容器引擎优先Podman；AppImage/deb/rpm多格式分发 |

## 二、性能指标

| 序号 | 性能项 | 指标值 |
|------|--------|--------|
| 1 | **并发扫描任务** | 支持≥10个扫描任务并行执行（容器隔离） |
| 2 | **扫描状态刷新** | 3秒自动轮询周期 |
| 3 | **API响应时间** | 常规CRUD接口 ≤200ms（本地SQLite直读） |
| 4 | **知识图谱加载** | 全量3,190节点+5,681边 ≤3s |
| 5 | **知识图谱检索** | 节点搜索 ≤500ms |
| 6 | **Playbook执行** | 单步骤超时可配置，步骤间串行执行，支持可选步骤跳过 |
| 7 | **AI Playbook生成** | 依赖LLM接口响应，典型2-5步骤Playbook生成 ≤30s（DeepSeek API） |
| 8 | **AI拓扑生成** | 基于扫描结果LLM推理 ≤30s |
| 9 | **工具输出上限** | 单次工具执行输出 ≤2MB |
| 10 | **容器引擎检测缓存** | 60秒缓存周期 |
| 11 | **数据库** | SQLite单文件，随软件分发，无需独立数据库服务 |
| 12 | **评分计算** | 步骤评分+MITRE覆盖率加分（最高20分），总分114分，A-F五级评定 |
| 13 | **前端内存占用** | Qt5原生应用，典型 ≤150MB RSS |

## 三、技术规格

| 项目 | 规格 |
|------|------|
| 前端框架 | Qt 5.15.3 / C++17 / CMake |
| 后端运行时 | Node.js（内嵌） |
| 数据库 | SQLite 3（单文件） |
| 容器引擎 | Podman（优先）/ Docker（回退） |
| 容器基础镜像 | Alpine 3.19 |
| AI接口 | OpenAI兼容API（默认DeepSeek） |
| 知识图谱数据 | HexStrike-AI + MITRE ATT&CK STIX |
| 分发格式 | AppImage / deb / rpm |
| 目标操作系统 | 银河麒麟 / 统信UOS / Ubuntu 22.04 |
