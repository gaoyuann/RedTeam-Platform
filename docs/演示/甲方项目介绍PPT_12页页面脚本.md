# 甲方项目介绍 PPT：13 页页面脚本（含目录）

> 先介绍项目与软件，再介绍软件架构、部署与功能演示；本稿不把待采集图片、未核验硬件参数和历史测试结果表述为已交付成果。

## 一、统一制作规范

- 汇报主线：项目定位 → 软件产品 → 软件架构 → 软硬件部署 → 模块闭环 → 功能演示 → 安全交付 → 建设价值。
- 模板与比例：使用 docs/演示/交大ppt模板.pptx，页面比例 16:9；封面使用“封面-2”，正文优先使用“内容页-单项图文”，结束页使用“尾页”。
- 字号建议：标题 30–34 pt，主结论 20–24 pt，正文 18–22 pt，图注与来源不小于 15 pt。
- 图片数量：每页以一张主图为主，最多两张；删去的小图改为文字说明，原始证据仍按材料矩阵留存。
- 占位符规则：图片、表格和实物素材均标注编号、待采集和用途；正式替换后删除占位提示。截图须脱敏账号、令牌、内部地址和无关敏感信息。
- 不确定信息：硬件型号、数量、网络地址、统计数值和功能结果以现场核验为准；未确认前只写通用架构和能力表述。
- 预计讲解时长：约 11 分 20 秒，不含现场操作和问答。
