# 云笔电操作手册：DVWA 演示流程

适用对象：第一次使用系统的同学。整理日期：2026-10-08。仅用于授权实验内网，不要公开传播账号和口令。

**这次只记住一条路线：登录系统 → 新建任务 → 查看扫描 → 选择黄金预案 → 查看执行与证据 → 导出报告。**

## 一、先认准本次目标

| 项目 | 本次使用的内容 |
| --- | --- |
| DVWA 地址 | `http://192.168.1.111:4280` |
| 使用的 Playbook（测试预案） | **DVWA 黄金杀伤链 (10工具饱和打击版 v2)** |
| 预案编号 | `golden_dvwa_max_tools` |

> 演示前和师兄确认一次：黄金预案已适配上述地址和 4280 端口，工具、字典及有效登录会话已准备好。旧模板里有本地地址、固定端口和会话值，不能直接认为换个目标地址就能全部跑通。

## 二、照着这 6 步操作

### 第 1 步：确认系统已连接

进入「系统管理 → 资源部署」，点击「检测后端连接」，确认显示已连接，再返回「测试任务」。

**不要改已有的服务器、模型或容器配置。** 平台主机是 `192.168.1.110`；DVWA 的 `192.168.1.111:4280` 是测试目标，不能填成平台服务器地址。

### 第 2 步：用浏览器确认 DVWA 能打开

1. 在云笔电浏览器打开 `http://192.168.1.111:4280`。
2. 如果出现 DVWA 登录页，通常使用用户名 `admin`、密码 `password`；若部署时改过，以师兄提供的账号为准。**这是靶场账号，不是系统的 `admin / admin`。**
3. 登录后进入「DVWA Security」，将安全级别设为 `Low`，点击「Submit」。如果无法打开或登录，先联系师兄，不要继续测试，也不要自行重置数据库。

浏览器登录用于查看靶场；**它不会自动把登录会话交给平台**，执行所需会话仍要由预案正确处理。

### 第 3 步：新建一个测试任务

1. 在「测试任务」点击「＋ 新建任务」。
2. 在「目标 IP / 网段 / URL」中完整填写 `http://192.168.1.111:4280`，不要漏掉 `http://` 或 `:4280`。
3. 保留勾选「攻击前需人工确认（推荐）」，点击「创建并开始」。本次不填网段，不测试未授权设备。
4. 在列表中**双击刚创建的任务**进入工作台，等待扫描、分析和预案生成。
5. 进入工作台的「脆弱性扫描」，选择当前任务的扫描记录，查看扫描结果。需要时点击「刷新任务列表」。

看到任务状态变为「待确认」是正常的：**系统在等你确认执行，不是卡住了。**

### 第 4 步：选择 DVWA 黄金预案并执行

1. 点击工作台顶部「确认预案并执行」。
2. 在「选择攻击预案」中选中 **DVWA 黄金杀伤链 (10工具饱和打击版 v2)**，核对编号为 `golden_dvwa_max_tools`。不要直接沿用默认选中的智能生成预案。
3. 再核对目标是 `http://192.168.1.111:4280`，点击「批准并执行」。

如果找不到黄金预案，或提示预检未通过、目标不兼容、缺少工具/字典/会话，**截图交给师兄处理，不要关闭检查或随便换预案**。

### 第 5 步：查看执行步骤和证据

1. 进入「漏洞攻击 → 执行记录」，选择本次记录，记下「执行编号」（`run_...`）。
2. 在「执行详情 → 执行步骤」查看每一步；双击步骤可看完整输出，在「证据」中查看发现。
3. 预案大体覆盖：端口探测、Web 指纹、漏洞初筛、目录枚举、登录与弱口令、SQL 注入、参数发现等；实际执行情况以页面记录为准。
4. 等状态结束后再做评估。`RUNNING` 是执行中，`COMPLETED` 是执行结束，`FAILED` 是失败，`CANCELLED` 是取消。没有更新时先点「刷新」，不要重复点击执行。

**步骤成功只代表工具执行成功，不等于漏洞已确认，也不保证 100 分。** 失败时保留执行编号、失败步骤和完整输出；需要中止时使用「停止执行」或顶部「⋯ → 取消任务」。

### 第 6 步：生成并保存报告

1. 进入「测试评估 → 执行评分」，核对选中的是本次执行编号；若没有评分，点击「评分」。
2. 评分显示后，点击「生成测试报告」。
3. 进入「测试报告」，选中刚生成的报告，选择 `DOCX`，点击「导出报告」，保存到桌面或自己指定的文件夹。
4. 用 WPS 打开导出的文件，检查目标地址、执行编号、步骤结果和证据是否对应本次任务。可以同时保存关键步骤的截图。

**本次应交付：一份报告 + 本次执行编号 + 关键结果/失败截图。** 有失败或待复核项就如实保留，不把工具输出或模型文字直接当作已验证漏洞。

## 三、以后只想重跑黄金预案

进入「预案与知识库 → Playbook 库」，将「基线组」设为「全部」，选中上述黄金预案，点击「▶ 前往执行此预案」；填写目标 `http://192.168.1.111:4280`，点击「执行」。之后按第 5、6 步查看结果并导出报告。

这是直接执行已有预案，**不会重新走完整的新建任务流程**。仍需满足前面的预案适配条件。
