# 服务器部署与自动更新指南

> 目标服务器：Ubuntu 22.04 (x86_64) — 便携式 AI 算力主站
> 仓库地址：`https://github.com/gaoyuann/RedTeam-Platform.git`
> 日期：2026-08-13

---

## 一、首次部署（从零到跑通）

### 1.1 基础环境安装

```bash
# 克隆项目
cd /opt
sudo git clone https://github.com/gaoyuann/RedTeam-Platform.git
cd RedTeam-Platform

# 一键安装服务器环境（Node.js + Docker + 编译工具链）
sudo bash scripts/setup-server.sh
```

脚本会自动安装：
- Node.js 20 LTS + npm
- Docker Engine + Compose
- gcc/g++/cmake/python3（npm 原生模块编译）
- 后端 npm 依赖（`npm install`）

> ⚠️ 安装完成后**重新登录 SSH**，使 Docker 组权限生效。

### 1.2 配置环境变量

```bash
# 创建环境配置文件
cat > /opt/RedTeam-Platform/.env << 'EOF'
# ── 服务绑定 ────────────────────────────────
HOST=0.0.0.0
PORT=3002

# ── JWT 密钥（生产环境必须改！）──────────────
JWT_SECRET=changeme-to-a-random-64-char-string

# ── 数据目录 ────────────────────────────────
REDTEAM_DATA_DIR=/opt/RedTeam-Platform/data
EOF

# 生成安全的 JWT_SECRET
sed -i "s/changeme-to-a-random-64-char-string/$(openssl rand -hex 32)/" /opt/RedTeam-Platform/.env
```

### 1.3 构建容器镜像（渗透工具）

```bash
cd /opt/RedTeam-Platform
bash scripts/build-images.sh
```

这会构建 9 个工具容器镜像：`rt-recon`、`rt-brute`、`rt-exploit`、`rt-vuln-scan`、`rt-credential`、`rt-web`、`rt-cloud`、`rt-system`。

> 首次构建较慢（需下载基础镜像 + 安装工具），约 10-30 分钟。

### 1.4 启动后端

```bash
cd /opt/RedTeam-Platform

# 加载环境变量
source .env
export HOST PORT JWT_SECRET REDTEAM_DATA_DIR

# 启动
bash scripts/start-server.sh
```

### 1.5 验证部署

```bash
# ① 健康检查
curl http://localhost:3002/api/health
# 期望输出: {"status":"ok"}

# ② 数据库检查
curl http://localhost:3002/api/db-test
# 期望输出: {"status":"ok","source":"SQLite","tables":{...}}

# ③ 容器引擎检查
curl http://localhost:3002/api/container-test
# 期望输出: {"status":"ok","engine":"docker",...}

# ④ WebSocket 检查（用 wscat 或浏览器控制台）
# npm install -g wscat
wscat -c ws://localhost:3002/ws
# 连接成功即表示 WebSocket 正常

# ⑤ 从云笔电访问（替换为服务器实际 IP）
curl http://<服务器IP>:3002/api/health
# 期望: 同上，如果超时请检查防火墙
```

### 1.6 防火墙放行

```bash
# Ubuntu UFW
sudo ufw allow 3002/tcp
sudo ufw reload

# 或 iptables
sudo iptables -A INPUT -p tcp --dport 3002 -j ACCEPT
```

## 二、注册为 systemd 服务（开机自启 + 崩溃自动重启）

```bash
sudo tee /etc/systemd/system/redteam-backend.service << 'EOF'
[Unit]
Description=RedTeam Platform Backend
After=network.target docker.service
Requires=docker.service

[Service]
Type=simple
User=redteam
Group=redteam
WorkingDirectory=/opt/RedTeam-Platform/backend
EnvironmentFile=/opt/RedTeam-Platform/.env
ExecStart=/usr/bin/node src/server.js
Restart=always
RestartSec=5
StandardOutput=journal
StandardError=journal
SyslogIdentifier=redteam-backend

# 安全加固
NoNewPrivileges=true
ProtectSystem=strict
ReadWritePaths=/opt/RedTeam-Platform/data

[Install]
WantedBy=multi-user.target
EOF

# 创建服务用户（如果不存在）
sudo id redteam &>/dev/null || sudo useradd -r -s /bin/false redteam
sudo usermod -aG docker redteam
sudo chown -R redteam:redteam /opt/RedTeam-Platform

# 启用并启动
sudo systemctl daemon-reload
sudo systemctl enable redteam-backend
sudo systemctl start redteam-backend

# 查看状态
sudo systemctl status redteam-backend

# 查看日志
sudo journalctl -u redteam-backend -f
```

## 三、自动更新（仓库有更新 → 自动拉取 + 重启）

### 方案 A：Git Auto-Pull 守护脚本（推荐，简单可靠）

创建自动更新脚本，每 30 秒轮询远程仓库，有新提交时自动拉取并重启后端：

```bash
sudo tee /opt/RedTeam-Platform/scripts/auto-update.sh << 'SCRIPT'
#!/usr/bin/env bash
# RedTeam Platform — 自动更新守护脚本
# 每 30 秒检查远程仓库，有新提交时自动拉取 + 重启后端
set -euo pipefail

REPO_DIR="/opt/RedTeam-Platform"
BRANCH="main"
POLL_INTERVAL=30
LOG_TAG="redteam-autoupdate"

cd "$REPO_DIR"

log() { echo "[$(date '+%Y-%m-%d %H:%M:%S')] [$LOG_TAG] $*"; }

log "Auto-update daemon started (branch=$BRANCH, interval=${POLL_INTERVAL}s)"

while true; do
  # 获取远程最新 commit hash（不拉取代码）
  REMOTE_HASH=$(git ls-remote origin "refs/heads/$BRANCH" 2>/dev/null | awk '{print $1}')
  LOCAL_HASH=$(git rev-parse "origin/$BRANCH" 2>/dev/null || echo "")

  if [ -z "$REMOTE_HASH" ]; then
    log "WARNING: Cannot reach remote, retrying in ${POLL_INTERVAL}s"
    sleep "$POLL_INTERVAL"
    continue
  fi

  if [ "$REMOTE_HASH" != "$LOCAL_HASH" ]; then
    log "New commit detected: $LOCAL_HASH → $REMOTE_HASH"
    log "Pulling updates..."

    # 拉取代码
    if git pull origin "$BRANCH" 2>&1; then
      log "Pull successful"

      # 重新安装 npm 依赖（package.json 可能变了）
      log "Installing dependencies..."
      (cd "$REPO_DIR/backend" && npm install --production 2>&1) || log "WARNING: npm install failed"

      # 重启后端服务
      log "Restarting backend..."
      sudo systemctl restart redteam-backend
      log "Backend restarted"

      # 更新本地的 origin/$BRANCH 引用
      git fetch origin "$BRANCH" 2>/dev/null || true
    else
      log "ERROR: git pull failed, skipping restart"
    fi
  fi

  sleep "$POLL_INTERVAL"
done
SCRIPT

sudo chmod +x /opt/RedTeam-Platform/scripts/auto-update.sh
```

注册为 systemd 服务：

```bash
sudo tee /etc/systemd/system/redteam-autoupdate.service << 'EOF'
[Unit]
Description=RedTeam Platform Auto-Update Daemon
After=network.target

[Service]
Type=simple
User=redteam
Group=redteam
WorkingDirectory=/opt/RedTeam-Platform
ExecStart=/opt/RedTeam-Platform/scripts/auto-update.sh
Restart=always
RestartSec=10
StandardOutput=journal
StandardError=journal
SyslogIdentifier=redteam-autoupdate

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable redteam-autoupdate
sudo systemctl start redteam-autoupdate

# 查看自动更新日志
sudo journalctl -u redteam-autoupdate -f
```

### 方案 B：GitHub Webhook（实时推送，需公网 IP）

如果服务器有公网 IP 或可被 GitHub 访问，可用 Webhook 实现实时更新（零延迟）：

```bash
# 安装 webhook 工具
sudo apt install -y webhook

# 创建 webhook 配置
sudo tee /etc/webhook/hooks.json << 'EOF'
[
  {
    "id": "redteam-deploy",
    "execute-command": "/opt/RedTeam-Platform/scripts/webhook-deploy.sh",
    "command-working-directory": "/opt/RedTeam-Platform",
    "pass-arguments-to-command": [ { "source": "payload", "name": "ref" } ],
    "trigger-rule": {
      "and": [
        { "match": { "type": "payload-hmac-sha256", "secret": "YOUR_WEBHOOK_SECRET", "parameter": { "source": "header", "name": "X-Hub-Signature-256" } } },
        { "match": { "type": "value", "value": "refs/heads/main", "parameter": { "source": "payload", "name": "ref" } } }
      ]
    }
  }
]
EOF

# 创建部署脚本
sudo tee /opt/RedTeam-Platform/scripts/webhook-deploy.sh << 'DEPLOY'
#!/usr/bin/env bash
cd /opt/RedTeam-Platform
git pull origin main
cd backend && npm install --production
sudo systemctl restart redteam-backend
DEPLOY

sudo chmod +x /opt/RedTeam-Platform/scripts/webhook-deploy.sh

# 启动 webhook 服务
webhook -hooks /etc/webhook/hooks.json -port 9000 -verbose &
```

然后在 GitHub 仓库 → Settings → Webhooks → Add webhook：
- Payload URL: `http://<服务器公网IP>:9000/hooks/redteam-deploy`
- Content type: `application/json`
- Secret: 与 `YOUR_WEBHOOK_SECRET` 一致

## 四、完整部署验证清单

在服务器上按顺序执行以下验证：

```bash
echo "=== 部署验证清单 ==="

# ① 系统服务状态
echo -n "[1/7] 后端服务: "; sudo systemctl is-active redteam-backend
echo -n "[2/7] 自动更新: "; sudo systemctl is-active redteam-autoupdate

# ③ Node.js 版本
echo -n "[3/7] Node.js: "; node -v

# ④ Docker 状态
echo -n "[4/7] Docker: "; docker info &>/dev/null && echo "running" || echo "stopped"

# ⑤ API 健康检查
echo -n "[5/7] API Health: "; curl -sf http://localhost:3002/api/health && echo "" || echo "FAIL"

# ⑥ 数据库检查
echo -n "[6/7] Database: "; curl -sf http://localhost:3002/api/db-test | python3 -c "import sys,json; d=json.load(sys.stdin); print('ok' if d['status']=='ok' else 'FAIL')" 2>/dev/null || echo "FAIL"

# ⑦ 容器镜像检查
echo -n "[7/7] Container images: "; docker images --format '{{.Repository}}' | grep ^rt- | wc -l; echo "  (expected: 9)"

echo "=== 验证完成 ==="
```

全部通过后，云笔电客户端可通过 `http://<服务器IP>:3002` 连接。
