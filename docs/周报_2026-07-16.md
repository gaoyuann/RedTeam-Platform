### 3.3 启动流程改造

`main.cpp` 实现了完整的启动链：

```
QApplication 初始化 → 暗色模式检测 → 全局样式表
    → SplashDialog(进度条+后端健康检查)
    → LoginDialog(用户认证)
    → MainWindow(7模块导航+功能页面)
```

- **暗色模式**：自动检测系统 Palette 或 QSettings 手动覆盖，两套完整样式表
- **Logo 资源**：`logo.png`（1408×768 RGBA）嵌入 Qt 资源系统
- **窗口尺寸**：统一 76% 屏幕尺寸，居中显示

### 3.4 MainWindow 改造

- 从 Phase 0 的"空壳占位页面"改为**7 个真实功能页面**的 QStackedWidget
- 新增**退出登录**按钮（回到 LoginDialog）
- 新增**全局 API 错误**信号 → 状态栏提示
- 页面切换时自动调用 `BasePage::refresh()` 刷新数据
