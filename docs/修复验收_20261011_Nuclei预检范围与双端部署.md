## 2. 修复内容

| 文件 | 变更 |
| --- | --- |
| `backend/src/services/nucleiTemplates.js` | 将必需模板 ID 解析为具体 YAML 文件路径；主机、Docker、Podman 校验均只加载这些文件；保留模板存在性和编译校验 |
| `backend/src/tools/toolRunner.js` | 实际执行复用解析出的文件路径，避免预检通过后又加载整套模板库 |
| `backend/test/nuclei-templates.test.js` | 新增 11 项回归测试，覆盖范围限制、缺失模板、损坏模板、多 ID、三种执行环境及参数兼容性 |

本地旧版本缺少服务器已有的编译校验代码，本次保留并同步了该能力，而非直接移除校验。

安全与兼容边界：

- 必需模板缺失或编译失败时仍然拒绝执行，不绕过预检。
- 同时指定多个模板 ID 时，校验所有匹配的必需文件。
- 不指定模板 ID 的全库扫描仍保留全库校验，本次未升级 Nuclei 镜像或处理无关模板库兼容问题。
- 显式模板路径及 `-duc` 参数保留原有行为。
