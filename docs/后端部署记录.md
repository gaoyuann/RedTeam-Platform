## 7. 部署过程中修复的问题

### 7.1 登录报 "Host requires authentication"

**现象**：Qt 前端登录时弹出 "Host requires authentication"  
**根因**：
1. 数据库 users 表为空 → 后端返回 HTTP 401 "用户名或密码错误"
2. Qt 将任何 401 映射为 `AuthenticationRequiredError`，用通用文本覆盖了真实错误消息

**修复**：
- `backend/src/db/migrations/007_add_auth_tables.js`：种子默认用户
- `frontend/src/ApiClient.cpp`：handleReply 中先读 JSON body 的 error.message，再 fallback 到 Qt errorString()
- `frontend/src/main.cpp`：禁用系统代理 `QNetworkProxy::setApplicationProxy(QNetworkProxy::NoProxy)`

### 7.2 Playbook 数量为 0

**现象**：前端显示 0 个 playbook，数据库 playbooks 表为空  
**根因**：`003_import_playbooks.js` 路径解析层级错误
- 迁移文件位于 `backend/src/db/migrations/`
- 原代码 `resolve(__dirname, '..', '..', '..', 'data', 'playbooks')` → 解析到 `backend/data/playbooks`（不存在）
- `existsSync()` 返回 false → fallback 到 `/opt/RedTeam-Edu/...`（服务器上也不存在）
- 最终 0 个 playbook 导入

**修复**：改为 4 层 `..` 上溯到项目根目录
```js
// 修复前
const PROJECT_PLAYBOOKS_DIR = resolve(__dirname, '..', '..', '..', 'data', 'playbooks');
// 修复后
const PROJECT_PLAYBOOKS_DIR = resolve(__dirname, '..', '..', '..', '..', 'data', 'playbooks');
```

**Git commit**：`9d7ab96 fix(migration003): correct path resolution — 4 levels up to project root`

### 7.3 Docker 构建失败（rt-recon）

**现象**：Docker build 时 wget 从 GitHub 下载 Go 二进制返回 407  
**根因**：服务器代理需认证，Docker 构建内 wget 未配置代理  
**修复**：在宿主机通过代理预下载 Go 二进制，Dockerfile 改为 COPY 本地文件

### 7.4 数据库 0 bytes

**现象**：删除 DB 后重启，redteam.db 为 0 bytes  
**根因**：migration 003 修复未部署到服务器，后端启动时 migration 003 仍读旧路径 → 导入 0 个 playbook，但 migration 标记为已执行 → 后续重启不会重跑  
**修复**：通过 SFTP 部署修正后的 003 文件 → 删除 DB → 重启后端 → 全部 12 个 migration 重新执行 → 40 个 playbook 成功导入

## 8. 重建数据库流程

如需完全重建数据库（清空所有数据，重新执行全部 migration）：

```bash
# 1. 停止后端
sudo systemctl stop redteam-backend

# 2. 删除数据库文件
rm -f /opt/RedTeam-Platform/data/redteam.db \
      /opt/RedTeam-Platform/data/redteam.db-shm \
      /opt/RedTeam-Platform/data/redteam.db-wal

# 3. 启动后端（自动执行全部 migration）
sudo systemctl start redteam-backend

# 4. 验证
sleep 3
sqlite3 /opt/RedTeam-Platform/data/redteam.db "SELECT COUNT(*) FROM playbooks;"
sqlite3 /opt/RedTeam-Platform/data/redteam.db "SELECT username,role FROM users;"
```

## 9. 云笔电前端部署

云笔电为 ARM64 飞腾 + 银河麒麟系统，只运行 Qt5 前端，连接服务器后端。

### 首次部署

```bash
# 安装依赖
sudo apt install qt5-default qtbase5-dev libqt5websockets5-dev cmake g++ make

# 拉取代码并编译
cd ~/RedTeam-Platform
git pull origin main
bash scripts/build-client-arm64.sh

# 启动（连接服务器）
bash scripts/run.sh 192.168.1.103:3002
```

### 增量更新

```bash
# 一键更新：git pull → 增量编译 → 重启前端
bash scripts/update-client.sh

# 或指定服务器地址
REDTEAM_SERVER=192.168.1.103:3002 bash scripts/update-client.sh
```
