## 功能与异常验收

- 上海日期、至少六位日序号；多连接并发创建不重号，跨日、重启、删除后保留发号高水位。索引拒绝重复编号，触发器拒绝修改编号，包括大小写变化。
- 历史任务按原时间稳定补号，内部 ID、状态、时间与关联步骤保持不变；重复迁移不改号，异常日期整体回滚。
- 同账号、同 `request_id` 和内容返回原任务；参数冲突返回 409。多连接并发重放只保存一个任务、一个请求映射；不同账号可使用相同请求标识。任务插入或请求映射失败时整个事务回滚。
- 精确编号和内部 ID 检索覆盖全部可见状态；普通文本支持名称、目标和类型。大小写、首尾空白及 `+`、`%`、`&`、`#` 按约定处理。无权和未知编号查找均返回不可访问结果。
- 搜索防抖、过时响应丢弃；任务切换和详情失败清除旧编号。旧后端缺少协议声明时显示内部 ID，不允许重放不支持幂等的创建请求；能力撤回后立即禁用待重试请求。
- 新报告 JSON、HTML、DOCX、PDF 保留冻结编号；历史报告补号后内容不改写，页面明确区分当前元数据和原快照。
- 普通完整创建仅保存待启动任务；既有快速及拓扑创建的启动语义保留，测试中使用模拟启动接口，不执行扫描。

## 账号异步竞态

新增受控回归在真实认证、HTTP 和任务路由中暂停源码配置解析，在入口账号校验通过后停用、删除或改变该账号角色，再恢复异步处理。修复前停用和角色变化仍返回 201，删除账号则落入数据库错误。

现在保存函数取得立即写锁后复核账号有效性及请求角色，失效统一返回 401/AUTH_REQUIRED。回归核对任务、请求映射、计数表、步骤和扫描作业均无新增；恢复有效账号后用原请求创建，获得当天 `000001`。没有通过消耗编号后删除任务来实现拒绝。
