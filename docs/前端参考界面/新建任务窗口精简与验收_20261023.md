## 修改文件与行为

| 文件 | 修改 |
| --- | --- |
| `frontend/src/pages/FlowPage.cpp` | 重组共用创建表单、自动名称和类型、授权摘要及确认、兼容配置默认值和自适应布局 |
| `frontend/test/batch16_context_checks.cpp` | 补充创建、取消、失败、授权变化、隐藏输入隔离、布局和截图检查；保留既有拓扑与源码流程检查 |
| 本记录 | 记录范围、行为和验收结果 |

- 基础表单依次为任务名称、测试目标、任务类型。名称由目标、测试用途和时间生成，可编辑；清空名称仍可创建。
- HTTP/HTTPS、主机、网段、源码路径与 TCP 目标提供初始类型判断；手动调整后保留用户选择。
- 删除授权范围输入、其他授权目标、排除项、扫描位置、入口预算、靶场引用、认证配置引用，不提供高级设置入口。
- 授权目标自动展示为纯文本。源码任务的可选运行入口同时进入摘要和结构化范围；隐藏的运行入口不进入请求。目标或输入方式变化后重新确认授权。
- 固定提示后续执行验证需人工确认。保持原有 `require_approval=true` 和 `auto_execute=true` 请求语义，后端继续负责各模式策略及人工审批。
- 保持完整创建后待启动、快速创建及拓扑目标创建后请求启动的既有区别。
- 明确保留配置默认值：扫描端、空排除项、空环境和认证引用；完整创建补查预算为 5，快速创建为 3。该默认值兼容原窗口，未新增可编辑参数。

## 视觉变化

复用 `Theme::PageStyle`、主题颜色和现有按钮样式工具。窗口采用浅灰背景、白色表单卡片、浅蓝授权摘要、蓝色主操作和统一圆角。按钮去除平台原生图标。

普通模式内容紧凑；源码专用字段按类型整组显示。切回普通任务时重新计算布局和最小尺寸，去除残留空白。屏幕或缩放不足时只滚动内容区，授权确认和按钮固定可见；滚动可到达完整范围摘要。
