# 新建任务窗口精简与验收

日期：2026-10-23。范围为普通、快速和拓扑目标创建共用的窗口及对应回归；编号功能见 [任务ID验收](任务ID贯通与检索验收_20261023.md)。

## 参考、差距和修改

以用户确认的名称优先顺序、现有主界面以及 `410d6aab2cc1a4f31e4dac2f52c6d2e4.png` 的浅色卡片为依据。原窗口重复填写名称、目标和授权范围，包含不可用的扫描位置及认证选择，部分开关被固定配置覆盖；隐藏源码字段还会遗留空白。

`frontend/src/pages/FlowPage.cpp` 现在按“任务名称 → 测试目标 → 任务类型”排列；取消高级设置及已确定不需要的输入，使用主题背景、白色表单卡片、浅色授权摘要和统一按钮。`frontend/test/batch16_context_checks.cpp` 核对实际字段位置、创建行为、取消、失败及布局。

- 名称按目标、用途和时间生成，可编辑，清空后仍可创建。目标自动推断初始类型，用户手动选择后保留其选择。
- 删除授权范围输入、其他授权目标、排除项、扫描位置、入口预算、靶场引用和认证配置引用，不保留隐藏的高级设置入口。
- 自动展示本次授权目标。源码任务可选运行入口同时进入摘要和结构化范围；隐藏字段不进入请求。目标或输入方式变化后必须重新确认授权。
- 请求保留 `require_approval=true` 和 `auto_execute=true` 的既有语义。普通完整创建保存为待启动；快速及拓扑创建保留既有请求启动行为。实际扫描仍由后端及人工授权流程控制。
- 删除的输入使用明确兼容默认值：扫描端、空排除项、空环境及认证引用；完整创建补查预算 5，快速创建 3。
- 源码字段成组显示，回切普通任务重新计算布局。高 DPI 或小屏只滚动内容区，授权确认与操作固定可见。

## 当前版本验证

在最新 `origin/main` 的隔离 worktree 中按既有 Qt5/CMake 配置构建，未修改编译器、Qt 版本或架构。取屏幕沿用仓库的 `windowHandle()/QWindow::screen()` 兼容写法；本轮未安装或切换 Qt 5.12 工具链，不将本机构建宣称为 Qt 5.12 实机构建。`cmake --build build -j2` 和 `ctest --test-dir build -V` 通过；后者共 10 组，包含 100%、125%、150% 的上下文检查。完整后端、独立验证窗口及编号回归结果统一记录在任务ID验收文档。

真实 Qt 窗口连接隔离进程中的项目认证和任务路由，以临时 SQLite 创建一条待启动任务；复制编号、检索、详情及关闭重开后的持久化一致。未请求启动，也没有扫描作业、执行步骤或 Run。

截图位于本机 `.codex/task-identity-pr-20261023/create-visual/scale-{1,1.25,1.5}/`，包括主界面对照、普通表单、启用按钮、小屏、源码与目录模式、回切及滚动到底。已分别检查结构、颜色、间距、按钮状态和滚动可达性；任务名称位于首行，普通模式无遗留源码空白。截图与日志不提交。

未完成部署机原生窗口管理器下的人工复核。技能引用的 `docs/综合验收方案_20261011.md` 当前不存在，本轮采用既有统一验收手册和针对性检查。

## 限制

取消高级设置后，本窗口不能配置多目标授权或排除项；复杂范围须拆分为明确目标。历史任务配置不受影响。本次没有运行库迁移、完整服务栈、容器或远端操作，没有执行真实扫描。
