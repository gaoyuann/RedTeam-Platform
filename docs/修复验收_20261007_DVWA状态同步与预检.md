## GUI 验收清单

建议使用本地模拟服务或既有任务记录完成以下状态回归，不必启动新的探测或攻击：

1. 打开任务 A 的工作台，推送任务 B 完成事件：评分任务、分数和报告按钮不应切到 B。
2. 对当前任务模拟轮询终态，分别模拟 WebSocket 在线、断开及重复完成事件：均定位当前任务，不产生并发重复评分；失败后切换评估页签可重试。
3. 在任务 A 的详情或评分请求未返回时切到任务 B：A 的迟到响应不能覆盖 B；手动选择历史评分任务后，迟到的旧评分不能覆盖该选择。
4. 对拓扑模拟执行请求失败、`FAILED`、`CANCELLED`、`ABORTED`、持续请求失败：轮询结束或达到失败上限，不生成拓扑，原因可见。
5. 模拟任务 A 完成前用户切到任务 B：不能自动生成 A 的拓扑覆盖 B；重复点击生成不能并发打开多个进度流程。
6. 保持审批机制开启，区分等待审批、失败及取消的显示状态；不通过关闭审批规避问题。

## 二次复查（2026-10-07）

用户要求“再次检查”后，复查不是仅重跑编译，而是对评分、拓扑和预检做模拟行为核验；所有 HTTP 请求均进入仅绑定 `127.0.0.1` 随机端口的临时模拟服务，没有连接真实后端或靶场。

### 发现并补修的漏项

1. 报告生成回调未验证任务是否切换：模拟中先为 A 生成报告，再清空或切到 B，A 的迟到响应会重新启用报告按钮。现增加报告请求版本校验、当前评分任务校验和按钮复位。
2. 运行列表排序后使用排序前的行号：模拟中指定 `run_Z`，按编号升序排序后实际切到 `run_A`。现按排序后的任务 ID 恢复选择，列表刷新不再自动点击另一行；手动换任务停止旧任务的显示轮询。
3. 拓扑 404 判断与 API 返回不一致：无业务错误码的 HTTP 404 会被 `ApiClient` 转为 Qt `ContentNotFoundError` 编号，而非字符串 `404`。现兼容该错误码；失败提示刷新增加版本保护，生成回调校验当前任务，生成按钮随选中任务真实状态更新。
4. 已知变量非空并不代表配置可用：`dvwa_cookie` 默认包含 `PHPSESSID=placeholder`；`{{target}}`、`{{<target>}}` 和 `{{ host }}` 也不符合现有渲染契约。现预检阻断这些形式和显式占位值，不修改执行器来替换或补齐它们。
5. 字典检查仅查看变量值，漏掉后缀：原检查将 `{{wordlist_small}}/missing.txt` 当作已有字典本身通过。现检查资源变量替换后完整路径；宿主模式不再错误地用项目字典目录代替 `/usr/share/wordlists/...`。

## 公共组件销毁修复（2026-10-07）

用户同意修复后，本轮只修改公共视觉组件 `frontend/src/UiUtil.h`，不扩展攻击功能或资源下载。

根因：提示标签在视口销毁时先释放，作为视图子对象的辅助对象仍接收模型信号；模型销毁时发出的 `modelReset` 回调使用已失效的标签。

修复措施：辅助对象改为标签的子对象；标签、视口、模型使用 `QPointer`；回调直接检查其连接的模型，不再读取销毁中的视图；附加提示时立即同步可见性，保留原有样式与居中行为。
