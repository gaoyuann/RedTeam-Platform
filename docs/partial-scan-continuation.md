# 扫描部分完成后继续任务

普通 ReAct 网络测试恢复“有可用检查结果就继续分析”的行为：调度正常结束、至少一项检查按原能力契约取得完整可用证据、工具停止已确认时，其他子检查超时、失败或缺少条件不会单独阻断整个任务。

阶段状态 `completed` 表示扫描调度阶段结束；`output_data.completeness=incomplete` 与 `warning` 明确记录部分完成。客户端阶段摘要显示“部分完成”，任务日志保留警告。任务级扫描审计仍为 `PARTIAL`，各子扫描、工具证据及未检测状态保持原样；这不表示扫描完整、发现已验证或攻击成功。

全部检查没有可用证据、只有未开展 SQL 检测的页面读取、模型断线或无效调度、预算中断、用户取消、工具停止未确认时仍阻断后续分析。单个能力的证据完整性要求未放宽。后续生成、手选预案、提审和审批沿用现有流程。

适用于加载更新后的新运行；不回写历史失败扫描、不自动重试原任务。历史失败任务有有效漏洞候选且工具停止已确认时，仍可通过显式手选已有预案继续。

验证覆盖：成功观察加工具超时可继续且保留 PARTIAL；已有结果不能掩盖模型失败、取消或停止未知；全部失败及未启动 SQL 工具仍阻断。
