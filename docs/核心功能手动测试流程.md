## 1. 应用启动与登录

### 1.1 启动应用

| 项目 | 内容 |
|------|------|
| **前置条件** | 后端已启动（`bash scripts/start.sh` 会自动启动后端再启动前端） |
| **操作** | 运行 `bash scripts/start.sh`，或直接运行 `./build/frontend/RedTeam-Platform` |
| **预期** | 1. 弹出**启动画面（Splash）**，深色渐变背景，显示 Logo + "信息系统渗透智能化测试平台"<br>2. 进度条从 0% → 10%（"Loading resources..."）→ 30%（"Loading fonts..."）→ 80%（"Backend connected" 或 "Backend not connected"）→ 100%（"Ready"）<br>3. 启动画面约 0.4 秒后自动消失 |

### 1.2 登录界面 — 正确登录

| 项目 | 内容 |
|------|------|
| **前置条件** | 启动画面消失后，弹出**登录对话框** |
| **操作** | 1. 在「用户名」输入框输入已有用户名（如 `admin`）<br>2. 在「密码」输入框输入对应密码<br>3. 点击 **「登  录」** 按钮（蓝色主按钮） |
| **预期** | 1. 登录按钮文字变为「验证中...」并短暂禁用<br>2. 登录对话框关闭<br>3. **主窗口**弹出，左上角标题"信息系统渗透智能化测试平台" |

### 1.3 登录界面 — 错误密码

| 项目 | 内容 |
|------|------|
| **操作** | 1. 输入正确用户名<br>2. 输入错误密码<br>3. 点击 **「登  录」** |
| **预期** | 1. 登录对话框**不关闭**<br>2. 输入框下方出现红色错误提示：「用户名或密码错误」<br>3. 密码框被清空，光标自动聚焦到密码框 |

### 1.4 登录界面 — 记住密码

| 项目 | 内容 |
|------|------|
| **操作** | 1. 勾选 **「记住密码」** 复选框<br>2. 输入用户名和密码<br>3. 点击 **「登  录」**<br>4. 退出应用后重新启动 |
| **预期** | 重新打开登录界面时，用户名和密码**自动填充**上次保存的值 |

### 1.5 登录界面 — 退出按钮

| 项目 | 内容 |
|------|------|
| **操作** | 点击 **「退出」** 按钮（灰色按钮） |
| **预期** | 登录对话框关闭，应用完全退出 |

### 1.6 登录界面 — 密码可见切换

| 项目 | 内容 |
|------|------|
| **操作** | 点击密码输入框**右侧的眼睛图标** |
| **预期** | 密码从 `●●●●` 切换为明文显示，再次点击切换回密文 |

### 1.7 登录界面 — Enter 键快捷操作

| 项目 | 内容 |
|------|------|
| **操作** | 1. 用户名框输入完成后按 **Enter** → 光标跳到密码框<br>2. 密码框输入完成后按 **Enter** → 触发登录（等同于点击登录按钮） |

### 3.4 LLM 配置 — 回显验证

| **操作** | 保存 LLM 配置后，切换到其他页面再切回来 |

### 3.6 容器镜像表格

## 4. 脆弱性扫描

> 切换到左侧导航 **「脆弱性扫描」**

### 4.1 创建端口扫描任务

| 项目 | 内容 |
|------|------|
| **操作** | 1. 在 **目标地址** 输入框输入 `127.0.0.1`<br>2. 在 **扫描类型** 下拉框选择 `port_scan`<br>3. （可选）在 **端口** 输入框输入 `22,80`<br>4. 点击 **「创建扫描」** 按钮（蓝色主按钮） |
| **预期** | 1. 下方任务表格新增一行，显示任务ID、目标 `127.0.0.1`、类型 `port_scan`、状态 `PENDING`<br>2. 扫描**自动开始执行**（状态变为 `RUNNING`）<br>3. 页面每 3 秒自动轮询状态 |

### 4.2 创建漏洞扫描任务

| 项目 | 内容 |
|------|------|
| **操作** | 1. 目标地址输入 `http://testphp.vulnweb.com`<br>2. 扫描类型选择 `vuln_scan`<br>3. 点击 **「创建扫描」** |
| **预期** | 任务表格新增 `vuln_scan` 类型的任务 |

### 4.3 创建 Web 扫描任务

| 项目 | 内容 |
|------|------|
| **操作** | 1. 目标地址输入 `http://testphp.vulnweb.com/artists.php?artist=1`<br>2. 扫描类型选择 `web_scan`<br>3. 点击 **「创建扫描」** |
| **预期** | 任务表格新增 `web_scan` 类型的任务 |

### 4.4 创建暴力破解任务

| 项目 | 内容 |
|------|------|
| **操作** | 1. 目标地址输入 `ssh://192.168.1.1`<br>2. 扫描类型选择 `brute_force`<br>3. 点击 **「创建扫描」** |
| **预期** | 任务表格新增 `brute_force` 类型的任务 |

### 4.5 扫描参数配置

| 项目 | 内容 |
|------|------|
| **操作** | 切换不同扫描类型，观察参数区变化 |
| **预期** | - `port_scan`：提示「端口扫描参数（nmap）」，端口/超时/线程输入框可用<br>- `vuln_scan`：提示「漏洞扫描参数（nuclei）」<br>- `web_scan`：提示「Web扫描参数（sqlmap）」<br>- `brute_force`：提示「暴力破解参数（hydra）」 |

### 4.6 手动执行扫描

| 项目 | 内容 |
|------|------|
| **前置条件** | 有一个状态为 `PENDING` 的扫描任务 |
| **操作** | 1. 在任务表格中**点击选中**该 PENDING 任务<br>2. 点击 **「▶ 执行扫描」** 按钮 |
| **预期** | 1. 按钮触发执行，任务状态变为 `RUNNING`<br>2. 自动开始 3 秒轮询 |

### 4.7 查看扫描结果

| 项目 | 内容 |
|------|------|
| **前置条件** | 有一个状态为 `COMPLETED` 的扫描任务 |
| **操作** | 在任务表格中**点击选中**该 COMPLETED 任务 |
| **预期** | 1. 下方 **结果表格** 显示扫描结果，4 列：类型、严重度、数据、工具<br>2. 端口扫描结果：类型 `open_port`，数据含端口号和服务名<br>3. 漏洞扫描结果：类型 `vulnerability`，含严重度等级 |

### 4.8 查看 Playbook 推荐

| 项目 | 内容 |
|------|------|
| **前置条件** | 选中一个有扫描结果的 COMPLETED 任务 |
| **操作** | 查看任务表格下方的 **推荐表格** |
| **预期** | 推荐表格 4 列（名称、难度、基线组、匹配原因），按匹配分数从高到低排列。<br>如：发现 22 端口开放 → 推荐 SSH 相关 Playbook |

### 4.9 AI 生成 Playbook

| 项目 | 内容 |
|------|------|
| **前置条件** | 选中 COMPLETED 任务，且 LLM API Key 已配置 |
| **操作** | 点击 **「AI 生成 Playbook」** 按钮（蓝色主按钮） |
| **预期** | 1. 按钮短暂禁用，状态标签显示「正在生成...」<br>2. 生成完成后：状态标签显示 🟢「Playbook 生成成功: XXX（N 步）」<br>3. 若未配置 API Key：显示 🔴「No LLM API key configured」 |

### 4.10 刷新任务列表

| 项目 | 内容 |
|------|------|
| **操作** | 点击 **「刷新任务列表」** 按钮 |
| **预期** | 任务表格重新加载所有扫描任务 |

### 4.11 目标地址历史记录

| 项目 | 内容 |
|------|------|
| **操作** | 1. 创建扫描时输入目标地址 `192.168.1.1`<br>2. 清空目标地址输入框<br>3. 再次点击输入框 |
| **预期** | 输入框弹出**自动补全下拉列表**，包含之前输入过的目标地址 |

## 5. 漏洞利用想定与预案

> 切换到左侧导航 **「漏洞利用想定与预案」**

### 5.1 查看 Playbook 列表

| 项目 | 内容 |
|------|------|
| **操作** | 进入页面，观察左侧 **Playbook 列表表格** |
| **预期** | 表格 4 列（名称、难度、基线组、步骤数），列出所有非 AI 生成的 Playbook |

### 5.2 按基线组过滤

| 项目 | 内容 |
|------|------|
| **操作** | 在 **「基线组」** 下拉框中选择不同选项：`全部` / `侦察` / `Web漏洞扫描` / `Windows利用` / `后渗透` / `内网横向` / `本地安全检查` / `影响演示` / `域信息收集` |
| **预期** | 列表只显示对应基线组的 Playbook |

### 5.3 显示/隐藏 AI 生成 Playbook

| 项目 | 内容 |
|------|------|
| **操作** | 勾选/取消 **「含AI生成」** 复选框 |
| **预期** | - 勾选：列表包含 `is_generated = 1` 的 AI 生成 Playbook<br>- 取消：列表只显示手动/静态 Playbook |

### 5.4 查看 Playbook 详情

| 项目 | 内容 |
|------|------|
| **操作** | 在列表表格中**点击选中**一个 Playbook 行 |
| **预期** | 右侧 **详情树形控件** 显示该 Playbook 的步骤：<br>4 列（步骤、工具、描述、参数模板）<br>每个步骤显示工具名和参数模板（如 `["-sV", "<target>"]`） |

### 5.5 快速执行 Playbook

| 项目 | 内容 |
|------|------|
| **前置条件** | 已选中一个 Playbook |
| **操作** | 1. 在右侧 **目标地址** 输入框输入目标（如 `192.168.1.1`）<br>2. 点击 **「执行此 Playbook」** 按钮（蓝色主按钮） |
| **预期** | 1. 按钮短暂禁用<br>2. 状态标签显示「执行已启动: run_xxx」<br>3. 目标地址自动保存到历史记录 |

### 5.6 新建 Playbook

| 项目 | 内容 |
|------|------|
| **操作** | 1. 点击 **「＋ 新建」** 按钮（蓝色主按钮）<br>2. 在弹出的对话框中填写：<br>   - 名称（必填，如「自定义扫描」）<br>   - 描述<br>   - 基线组（下拉选择）<br>   - 难度（入门/初级/中级/高级）<br>   - 分类<br>   - 目标类型<br>3. 点击 **「确定」** |
| **预期** | 1. 对话框关闭<br>2. 列表表格新增刚创建的 Playbook（步骤数为 0） |

### 5.7 删除 Playbook

| 项目 | 内容 |
|------|------|
| **前置条件** | 选中一个 Playbook |
| **操作** | 点击 **「删除选中」** 按钮（红色危险按钮） |
| **预期** | 1. 弹出确认对话框「确定删除 Playbook "XXX"？」<br>2. 点击「是」后，该 Playbook 从列表消失 |

## 6. 漏洞攻击测试

> 切换到左侧导航 **「漏洞攻击测试」**

### 6.1 按攻击类别过滤 Playbook

| 项目 | 内容 |
|------|------|
| **操作** | 点击攻击类别单选按钮：<br>- **「全部」**（默认）<br>- **「数据窃取」**<br>- **「信息篡改」**<br>- **「设备夺控」** |
| **预期** | Playbook 下拉框的选项随类别过滤：<br>- 全部：显示所有 Playbook<br>- 数据窃取：只显示 `brute`/`credential` 组<br>- 信息篡改：只显示 `vuln_scan`/`web` 组<br>- 设备夺控：只显示 `exploit` 组 |

### 6.2 执行 Playbook

| 项目 | 内容 |
|------|------|
| **操作** | 1. 在 **Playbook** 下拉框选择一个 Playbook<br>2. 在 **目标地址** 输入框输入目标（如 `192.168.1.1`）<br>3. 点击 **「执行」** 按钮（蓝色主按钮） |
| **预期** | 1. 状态标签显示「执行已启动」<br>2. 下方 **运行表格** 新增一行，状态 `PENDING` 或 `RUNNING`<br>3. 目标地址保存到历史 |

### 6.3 查看运行列表

| 项目 | 内容 |
|------|------|
| **操作** | 查看 **运行表格** |
| **预期** | 表格 5 列（Run ID、Playbook、目标、状态、创建时间），按创建时间倒序 |

### 6.4 查看执行步骤详情

| 项目 | 内容 |
|------|------|
| **操作** | 在运行表格中**点击选中**一个 Run 行 |
| **预期** | 1. 下方 **步骤详情表格** 显示该 Run 的每步执行情况，5 列（步骤、工具、参数、成功、输出摘要）<br>2. 成功的步骤「成功」列显示 ✅，失败显示 ❌ |

### 6.5 查看攻击证据

| 项目 | 内容 |

## 11. 端到端完整工作流

> ⭐ **最重要的测试**：验证「**扫描 → 推荐 → 执行 → 评分 → 报告**」完整链路

### Step 1：启动与登录

1. 运行 `bash scripts/start.sh`
2. 等待启动画面消失
3. 在登录界面输入管理员账号密码，点击 **「登  录」**
4. ✅ 主窗口弹出

### Step 2：配置 LLM（如需 AI 功能）

1. 点击左侧导航 **「渗透测试资源部署配置」**
2. 在 LLM 配置区填写 API Key / Base URL / Model
3. 点击 **「保存 LLM 配置」**
4. 点击 **「测试连接」**，确认显示 🟢 连接成功
5. ✅ LLM 可用

### Step 3：创建并执行扫描

1. 点击左侧导航 **「脆弱性扫描」**
2. 目标地址输入 `127.0.0.1`
3. 扫描类型选择 `port_scan`
4. 端口参数输入 `22,80`
5. 点击 **「创建扫描」**
6. ✅ 任务表格新增任务，状态自动变为 `RUNNING` → `COMPLETED`
7. ✅ 结果表格显示 `open_port` 类型的扫描结果

### Step 4：查看 Playbook 推荐

1. 点击选中 COMPLETED 的扫描任务
2. ✅ 推荐表格显示按分数排序的 Playbook 列表

### Step 5：AI 生成 Playbook（可选）

1. 点击 **「AI 生成 Playbook」**
2. 等待生成完成
3. ✅ 提示生成成功，显示名称和步骤数

### Step 6：执行 Playbook

1. 点击左侧导航 **「漏洞利用想定与预案」**
2. 在列表中选中一个 Playbook
3. 在目标地址框输入 `127.0.0.1`
4. 点击 **「执行此 Playbook」**
5. ✅ 提示执行已启动

### Step 7：查看执行结果

1. 点击左侧导航 **「漏洞攻击测试」**
2. 在运行表格中点击选中刚创建的 Run
3. ✅ 步骤表格显示每步执行情况
4. ✅ 证据表格显示攻击证据

### Step 8：评分

1. 点击左侧导航 **「测试评估」**
2. 在 **「执行评分」** Tab 的 Run 下拉框选择刚完成的 Run
3. 点击 **「评分」**
4. ✅ 显示总分、百分比、等级（A/B/C/D/F）
5. ✅ 步骤评分表格显示每步得分
6. ✅ MITRE 覆盖率显示

### Step 9：生成报告

1. 点击 **「生成测试报告」**
2. 切换到 **「测试报告」** Tab
3. ✅ 新报告出现在列表
4. 点击报告行
5. ✅ 右侧显示报告内容

### Step 10：生成网络拓扑（可选）

1. 点击左侧导航 **「网络拓扑探测与绘制」**
2. 选中 COMPLETED 的扫描任务
3. 点击 **「生成拓扑」**
4. ✅ 画布上显示网络拓扑图
5. 点击节点查看详情
6. 拖拽节点调整位置
7. 点击 **「保存」**

### Step 11：退出登录

1. 点击状态栏 **「退出登录」**
2. 确认退出
3. ✅ 返回登录界面
