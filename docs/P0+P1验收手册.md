# P0 + P1 改造验收手册

> 在本机（WSL2 Ubuntu 22.04）逐步执行以下验收步骤，确认所有改造生效。

---

## 一、P0 改造内容回顾

| 改造项 | 内容 |
|--------|------|
| 网络架构 C/S 分离 | 后端绑定 `0.0.0.0`，前端服务器地址可配置 |
| JWT 认证 | 登录返回 access_token + refresh_token，所有 API 需 Bearer token |
| RBAC 权限控制 | admin/teacher/operator/student/viewer 五角色，路由级权限守卫 |
| 密码加密 | 明文→bcrypt 惰性升级 |
| 部署脚本拆分 | start-server.sh + start-client.sh，start.sh 保持单机兼容 |

## 二、P1 改造内容回顾

| 改造项 | 内容 |
|--------|------|
| 前端角色化 UI | MainWindow 接收 role/username，BasePage 增加 m_role，所有 Page 传递角色 |
| WebSocket 实时推送 | 后端 wsManager 广播扫描/执行事件，前端 WsClient 条件编译 |

### 3.3 健康检查

```bash
curl -s http://127.0.0.1:3002/api/health | python3 -m json.tool
```

**验收标准**：返回 `{"status": "ok", "timestamp": "...", "uptime": ...}`

### 3.4 JWT 登录验收

```bash
# 登录 admin
curl -s -X POST http://127.0.0.1:3002/api/users/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"admin"}' | python3 -m json.tool
```

**验收标准**：返回 JSON 包含

```json
{
  "status": "ok",
  "data": {
    "username": "admin",
    "role": "admin",
    "access_token": "eyJhbGciOiJIUzI1NiIs...",
    "refresh_token": "8dfb6c2753c...",
    "expires_in": 7200
  }
}
```

> 如果之前已登录过，密码可能已升级为 bcrypt，仍应正常登录

---

### 3.5 Token 认证验收

```bash
# 提取 token（复制上一步返回的 access_token）
TOKEN="eyJhbGciOiJIUzI1NiIs..."  # 替换为实际 token

# 带 token 访问受保护路由
curl -s http://127.0.0.1:3002/api/scan-tasks \
  -H "Authorization: Bearer $TOKEN" | python3 -c "import sys,json; d=json.load(sys.stdin); print(f'status={d[\"status\"]}, count={len(d.get(\"data\",[]))}')"

# 不带 token 访问（应返回 401）
curl -s http://127.0.0.1:3002/api/scan-tasks | python3 -m json.tool
```

**验收标准**：
- 带 token → `status=ok, count=XX`（XX 为扫描任务数量）
- 不带 token → `{"status": "error", "error": {"message": "缺少认证令牌", "code": "AUTH_REQUIRED"}}`

---

### 3.6 RBAC 权限验收

```bash
# 登录 student
STUDENT_RESP=$(curl -s -X POST http://127.0.0.1:3002/api/users/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"student","password":"student"}')
STUDENT_TOKEN=$(echo "$STUDENT_RESP" | python3 -c "import sys,json; print(json.load(sys.stdin)['data']['access_token'])")

# student 读 scan-tasks（应成功）
echo "=== student 读 scan-tasks ==="
curl -s http://127.0.0.1:3002/api/scan-tasks \
  -H "Authorization: Bearer $STUDENT_TOKEN" | python3 -c "import sys,json; d=json.load(sys.stdin); print(f'status={d[\"status\"]}')"

# student 读 config（应被拒绝 403）
echo "=== student 读 config ==="
curl -s http://127.0.0.1:3002/api/config \
  -H "Authorization: Bearer $STUDENT_TOKEN" | python3 -m json.tool

# student 写 scan-tasks（应被拒绝 403）
echo "=== student 写 scan-tasks ==="
curl -s -X POST http://127.0.0.1:3002/api/scan-tasks \
  -H "Authorization: Bearer $STUDENT_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"target":"127.0.0.1","scan_type":"port"}' | python3 -m json.tool
```

**验收标准**：
- student 读 scan-tasks → `status=ok`
- student 读 config → `403 FORBIDDEN`
- student 写 scan-tasks → `403 FORBIDDEN`

---

### 3.7 Token 刷新验收

```bash
# 提取 refresh_token
REFRESH=$(echo "$STUDENT_RESP" | python3 -c "import sys,json; print(json.load(sys.stdin)['data']['refresh_token'])")

# 刷新 token
curl -s -X POST http://127.0.0.1:3002/api/users/refresh \
  -H 'Content-Type: application/json' \
  -d "{\"refresh_token\":\"$REFRESH\"}" | python3 -m json.tool
```

**验收标准**：返回新的 `access_token` 和 `refresh_token`

## 五、快速验收（一键脚本）

如果想一次性跑完所有后端 API 测试：

```bash
# 停止可能残留的进程
lsof -ti:3002 | xargs kill -9 2>/dev/null || true
sleep 1

# 启动后端
cd /home/gaoyuan/RedTeam-Platform/backend
HOST=127.0.0.1 node src/server.js &
sleep 3

# 批量测试
echo "=== 1. Health ===" && curl -sf http://127.0.0.1:3002/api/health | python3 -c "import sys,json; print(json.load(sys.stdin)['status'])"

echo "=== 2. Login ===" && LOGIN=$(curl -s -X POST http://127.0.0.1:3002/api/users/login -H 'Content-Type: application/json' -d '{"username":"admin","password":"admin"}') && echo "$LOGIN" | python3 -c "import sys,json; d=json.load(sys.stdin); print(f'role={d[\"data\"][\"role\"]}, has_token={bool(d[\"data\"].get(\"access_token\"))}')"

TOKEN=$(echo "$LOGIN" | python3 -c "import sys,json; print(json.load(sys.stdin)['data']['access_token'])")

echo "=== 3. With Token ===" && curl -s http://127.0.0.1:3002/api/scan-tasks -H "Authorization: Bearer $TOKEN" | python3 -c "import sys,json; d=json.load(sys.stdin); print(d['status'])"

echo "=== 4. Without Token ===" && curl -s http://127.0.0.1:3002/api/scan-tasks | python3 -c "import sys,json; d=json.load(sys.stdin); print(d['error']['code'])"

echo "=== 5. Student RBAC ===" && ST=$(curl -s -X POST http://127.0.0.1:3002/api/users/login -H 'Content-Type: application/json' -d '{"username":"student","password":"student"}') && STK=$(echo "$ST" | python3 -c "import sys,json; print(json.load(sys.stdin)['data']['access_token'])") && curl -s http://127.0.0.1:3002/api/config -H "Authorization: Bearer $STK" | python3 -c "import sys,json; d=json.load(sys.stdin); print(d['error']['code'])"

echo "=== 6. Refresh ===" && REF=$(echo "$LOGIN" | python3 -c "import sys,json; print(json.load(sys.stdin)['data']['refresh_token'])") && curl -s -X POST http://127.0.0.1:3002/api/users/refresh -H 'Content-Type: application/json' -d "{\"refresh_token\":\"$REF\"}" | python3 -c "import sys,json; d=json.load(sys.stdin); print(f'refresh ok={bool(d.get(\"data\",{}).get(\"access_token\"))}')"

echo "=== 7. Logout ===" && curl -s -X POST http://127.0.0.1:3002/api/users/logout -H "Authorization: Bearer $TOKEN" | python3 -c "import sys,json; print(json.load(sys.stdin)['status'])"

# 清理
lsof -ti:3002 | xargs kill -9 2>/dev/null || true
```

**预期全部输出**：

```
=== 1. Health ===
ok
=== 2. Login ===
role=admin, has_token=True
=== 3. With Token ===
ok
=== 4. Without Token ===
AUTH_REQUIRED
=== 5. Student RBAC ===
FORBIDDEN
=== 6. Refresh ===
refresh ok=True
=== 7. Logout ===
ok
```
