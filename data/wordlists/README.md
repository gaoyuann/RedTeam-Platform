# 内置教学字典

`common_passwords.txt` 是面向已授权 DVWA 等隔离靶场的小型弱口令字典；`common_users.txt` 和 `common_dirs.txt` 用于配套验证。内容由项目维护，不依赖联网下载，不包含真实敏感凭据。

后端预检会在这些内置文件缺失时创建默认文件，保留已有文件（包括用户自定义内容），不静默覆盖空文件。其他缺失、空或不可读字典会阻断预检。

容器路径统一为 `/usr/share/wordlists/<文件名>`，宿主路径为项目 `data/wordlists/<文件名>`。旧 `config/wordlists/` 引用会映射到该位置。字典存在不代表认证已成功，认证结果必须另行确认。

宿主模式的字典参数也必须指向项目 `data/wordlists/` 下的文件；需要自定义字典时先放入该目录，不支持把任意系统文件作为字典参数。
